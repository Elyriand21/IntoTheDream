# 🌙 Into The Dream

**Into The Dream** is a 2D side-scrolling platformer built in Python using Pygame. Navigate surreal dreamscapes, defy gravity, and uncover the layers of a mysterious subconscious in this atmospheric experience.

## 🎮 Features

- Smooth character movement with jump and double-jump mechanics
- Directional animation with idle, run, jump, fall, and double-jump states
- Scrollable background for side-scrolling levels
- Sprite collision using pixel-perfect masks
- Modular and scalable level design using object-oriented programming

## 🛠️ Built With

- **Language**: Python 3
- **Library**: [Pygame](https://www.pygame.org/)

## 🚀 Getting Started

### Prerequisites

- Python 3.7+
- Pygame:
  ```bash
  pip install pygame
  ```

### Run the Game

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/into-the-dream.git
   cd into-the-dream
   ```
2. Run the game:
   ```bash
   python main.py
   ```

> Make sure the `assets/` folder is properly structured and included in the same directory.

## 🎮 Controls

| Key         | Action              |
|-------------|---------------------|
| `A`         | Move Left           |
| `D`         | Move Right          |
| `Spacebar`  | Jump / Double Jump  |
| `Esc`       | Quit Game           |

## 🧱 Known Limitations

- No enemy AI or hazards yet
- No level transitions or save/load system
- Collision only handled with ground blocks
